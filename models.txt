# Model manifest for the shared ComfyUI_Assets tree.
#
# Format, one entry per line:   <dest-path>  <bytes>  <url>
#
#   dest-path  relative to ComfyUI_Assets/, e.g. models/vae/foo.safetensors.
#              Written first so the layout reads at a glance, and so a file can
#              be renamed on the way in.
#   bytes      expected size, or "-" to look it up over the network. Used to
#              check free disk BEFORE a 20 GB download starts, to skip files
#              already complete, and to tell "complete" from "truncated".
#   url        direct download URL.
#
#              Use canonical huggingface.co/<repo>/resolve/main/... links.
#              Do NOT paste the us.aws.cdn.hf.co links the website hands you:
#              those carry Expires= and Signature= and stop working within
#              hours, so a manifest full of them is broken by tomorrow.
#
# Sets: a [name] header starts a set, and NOTHING downloads unless you ask for
# it by name — these are tens of gigabytes and cost real money on a rented box.
#
#     colossul-seats models minimax-h3        # on a running instance
#     colossul-seats models --list            # what's defined, and its size
#     MODEL_SETS=minimax-h3 ...               # at provision time
#
# Gated repos need a token:  export HF_TOKEN=hf_...
# It is read from the environment only and never stored here.
#
# Downloads resume. Re-running is cheap and safe: anything already at its full
# size is skipped, and a partial file continues from where it stopped.
