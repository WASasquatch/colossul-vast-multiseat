# Model manifest for the shared ComfyUI_Assets tree.
#
# Format, one entry per line:
#
#     <dest-path>  <url>              <- the easy way; size looked up for you
#     <dest-path>  <bytes>  <url>     <- size pinned
#
#   dest-path  relative to ComfyUI_Assets/, e.g. models/vae/foo.safetensors.
#              Written first so the layout reads at a glance, and so a file can
#              be renamed on the way in.
#   bytes      OPTIONAL. Never go hunting for a byte count to add a model: leave
#              it out and the size is fetched from the server before anything
#              downloads. Pinning it only saves one HEAD request per file, and
#              turns a file that silently changed upstream into a visible error.
#              Fill them all in automatically with:
#                  colossul-seats models --sizes > models.txt.new
#   url        direct download URL.
#
#              Use canonical huggingface.co/<repo>/resolve/main/... links.
#              Do NOT paste the us.aws.cdn.hf.co links the website hands you:
#              those carry Expires= and Signature= and stop working within
#              hours, so a manifest full of them is broken by tomorrow.
#
# A [name] header starts a set, and applies to every entry until the next one.
# Entries written before any header belong to the set "default".
#
# NOTHING downloads unless a set is named — these are tens of gigabytes and cost
# real money on a rented box. Name "all" to select every set at once.
#
# ── COMMANDS ────────────────────────────────────────────────────────────────
#
#   colossul-seats models --list
#       Every set defined here, its file count and total size. Instant, offline.
#
#   colossul-seats models --check [set...]
#       Resolve every URL, compare the server's size against this file, and
#       check free disk — without transferring a byte. Exits non-zero if
#       anything is wrong, so it can gate a script. With no set named, checks
#       all of them. Run this first: a dead link or gated repo shows up in
#       seconds instead of twenty minutes into a 40 GB download.
#
#   colossul-seats models minimax-h3
#       DOWNLOAD that set. Several may be named at once:
#           colossul-seats models minimax-h3 minimax-h3-ref2va
#
#   colossul-seats models --all
#       Download every set defined here. `colossul-seats models all` is the
#       same thing. Check the total with --list first.
#
#   colossul-seats models --sizes > /tmp/models.new
#       Print this file with every omitted byte count filled in from the
#       server, so sizes can be pinned without collecting them by hand.
#
# On a running instance this file lives at /opt/colossul/models.txt — edit it
# there and re-run the command; no rebuild needed. Edits are lost when the
# instance is destroyed, so put anything permanent in the repo copy.
#
# ── AT PROVISION TIME ───────────────────────────────────────────────────────
#
# Set MODEL_SETS to download automatically when the instance comes up, either
# as `-e MODEL_SETS=minimax-h3` in the Vast template's Docker Options, or as
# ENV MODEL_SETS=... in the Dockerfile. Comma- or space-separated:
#
#     MODEL_SETS=minimax-h3,minimax-h3-ref2va
#     MODEL_SETS=all                      # every set in this file
#     MODEL_SETS=default                  # only the entries with no [header]
#
# Prefer `all` over listing sets by hand: a set added here later is picked up
# automatically instead of being silently skipped by a stale list.
#
# Unset means no downloads. Seats start either way, so a slow or failed
# download never blocks the instance coming up.
#
# ── AUTHENTICATION ──────────────────────────────────────────────────────────
#
# Gated repos need HF_TOKEN. Set it as a Vast ACCOUNT-level environment
# variable, the same place GITHUB_TOKEN goes; `export HF_TOKEN=hf_...` works
# for a manual run. It is read from the environment only, is never written to
# this file, and is never printed to the log.
#
# ── RE-RUNNING ──────────────────────────────────────────────────────────────
#
# Always safe and cheap. Files already at their full size are skipped, and an
# interrupted transfer resumes where it stopped rather than starting over — so
# after a dropped connection, just run the same command again.
