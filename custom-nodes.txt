# Custom node packs installed into the shared ComfyUI on every instance.
#
# Format, one per line:      <git-url>[@ref]
#   ref may be a commit SHA, tag or branch. Omit it to track the default branch.
#
# EVERY PACK BELOW IS FROZEN to the commit it was at on 2026-08-09, so a rented
# instance months from now installs exactly what was tested — node packs update
# constantly and unpinned ones would drift under the artists. To move to current
# upstream, re-resolve deliberately and re-test:
#
#   while read -r u; do echo "$u@$(git ls-remote "$u" HEAD | cut -f1)"; done
#
# Blank lines and #comments ignored. Order is irrelevant: clones run in
# parallel, then each pack's requirements.txt is installed SEQUENTIALLY into the
# shared venv (concurrent pip into one venv corrupts it).
#
# Edit and re-run:  colossul-seats nodes
# Skip entirely:    SKIP_CUSTOM_NODES=1
#
# ── Derived from your workflows ─────────────────────────────────────────────
# This list was generated by resolving every node type used in
# comfyui_workflows/ and public/workflows/ against ComfyUI-Manager's
# extension-node-map.json, then set-covering. The comment after each entry is
# the nodes it supplies. Verify against a real run before trusting it fully -
# the registry has collisions between forks.
